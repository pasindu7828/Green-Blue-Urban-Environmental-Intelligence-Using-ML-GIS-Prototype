# Prototype Scope and Component Ownership

This unified frontend is designed to present the group project as **one university system** while preserving each research member's own component boundaries.

## Shared system-level elements

- login / prototype access
- project home / component selection
- Green-Blue UEI branding
- Kaduwela pilot framing
- profile and notification UI
- common responsive dashboard design language
- local mock/demo data policy
- proposal-safe disclaimer wording

## Component-level separation

### Urbanization Intelligence
Owns green-cover transition, built-up expansion, urbanization pattern/pressure, and land-development suitability/caution guidance.

### Urban Heat Intelligence
Owns LST mapping, trend classification, heat forecasting, explainable heat drivers, cooling scenarios, and cooling-priority planning.

### Wetland Intelligence
Owns urban wetland degradation, recurring seasonal waterlogging susceptibility, and flood-retention conservation/restoration priority.

### River Corridor Intelligence
Owns riverbank/channel change indicators, erosion-like/deposition-like change, river-edge vegetation buffer, built-up riverbank encroachment, and riverbank risk/protection priority.

The frontend intentionally avoids merging one member's research claims into another member's analytical pages.
